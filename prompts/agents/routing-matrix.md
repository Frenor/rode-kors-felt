# RKF Routing Matrix (Compact)

Use this matrix first, then apply overlays from `specialists-lite.md`.

## Core Routes
- New UI/screen: `frontend-engineer` + `ux`
- New API endpoint: `backend-engineer` + `frontend-engineer`
- Full-stack feature: `frontend-engineer` + `backend-engineer` + `qa`
- Frontend bug: `frontend-engineer` + `qa`
- Backend bug: `backend-engineer` + `qa`
- Accessibility/contrast/usability: `frontend-engineer` + `ux` + `qa`
- Infra/CI/deploy: `backend-engineer` + `devops`
- Sprint/plan split: `product`
- Field validation: `field-user`

## Conflict Priority
`Safety > Offline > Accessibility > GDPR > Performance > DX`
